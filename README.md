# Deep Hedging with Adversarial Networks for Option Pricing

This project explores the concept of **Deep Hedging** using a Recurrent Neural Network (RNN) in conjunction with a Generative Adversarial Network (GAN) approach. The goal is to train a hedging strategy that minimizes Conditional Value at Risk (CVaR) by learning from simulated market data and then evaluating its performance against traditional Black-Scholes delta hedging.

## Project Overview

The notebook follows these main steps:

1. **Data Loading and Preprocessing**: Initial market data (option minute prices) is loaded, filtered for a specific timestamp, and processed to extract future prices, option strike prices, and types (Call/Put). Time to expiration and a risk-free rate are also defined.
2. **Black-Scholes Model and Greeks**: Implementation of the classic Black-Scholes option pricing model, including calculations for Greeks (Delta, Gamma, Theta).
3. **Implied Volatility (IV) Solver**: A bisection method is implemented to numerically calculate the implied volatility from observed option prices.
4. **Initial Delta Hedging Simulation (using IV)**: A simulation of delta hedging is performed using the implied volatility derived from real market data. This serves as a baseline for understanding hedging performance.
5. **Explanation of P&L Equation**: A detailed breakdown of the Profit & Loss (P&L) equation used for evaluating hedging strategies, particularly from the hedger's perspective, is provided.
6. **Deep Hedging with GANs**:
   - **Synthetic Data Generation (GBM)**: Geometric Brownian Motion (GBM) is used to generate a large dataset of synthetic underlying asset price paths. This synthetic data is crucial for training the deep hedging model.
   - **Black-Scholes Option Prices and Deltas for Synthetic Paths**: For each synthetic price path, theoretical Black-Scholes option prices and their corresponding deltas are calculated. These serve as target values and input features for the RNN.
   - **Data Split**: The synthetic data is split into training and test sets to ensure robust evaluation of the deep hedger.
   - **Deep Hedging RNN Model Implementation**: A Recurrent Neural Network (RNN), specifically a GRU (Gated Recurrent Unit), is built using TensorFlow/Keras. This model takes current asset price, Black-Scholes delta, and time-to-expiration as input to predict the optimal delta hedge position.
   - **P&L Calculation and CVaR Loss (TensorFlow-compatible)**: TensorFlow-compatible functions are defined for calculating P&L (without transaction costs) and for computing the Conditional Value at Risk (CVaR) as the primary loss function for training.
   - **Custom Training Loop**: A custom training loop is implemented to train the deep hedger model. It optimizes the model's weights by minimizing the CVaR of the P&L on the synthetic training data.
7. **Adversarial Deep Hedging (GAN)**: The project then extends to an adversarial framework where:
   - An **AdversarialPathGenerator** (a separate LSTM-based model) is introduced. Its role is to generate price paths that are challenging for the hedger, pushing the hedger to learn more robust strategies.
   - A specialized `bs_delta_tf` function (TensorFlow-compatible) is used to calculate Black-Scholes deltas efficiently for entire paths.
   - An adversarial training loop is set up, where the Generator tries to maximize the hedger's CVaR loss, and the Deep Hedger tries to minimize its CVaR loss on the paths generated by the adversarial generator. This iterative process helps the hedger generalize better.
8. **Evaluation and Analysis**: The performance of the trained Deep Hedger is thoroughly evaluated and compared against the Black-Scholes Delta Hedger on both training and test sets. This includes:
   - Plotting P&L distributions using histograms.
   - Quantifying risk metrics such as Value at Risk (VaR) and Conditional Value at Risk (CVaR).
   - Analyzing the training and validation loss curves from the standard RNN training and the adversarial training.

- The project demonstrates how to implement a Black-Scholes option pricing model and calculate Greeks.
- It provides a practical example of traditional delta hedging.
- It introduces the methodology of Deep Hedging using RNNs to learn dynamic hedging strategies.
- Crucially, it showcases an advanced technique using GANs for adversarial training, where a generator creates challenging market scenarios, leading to a more robust deep hedger.
